# Spark Light

Shadow 的个人服务站。多文件静态项目，不需要安装任何东西、不需要构建，直接放进 GitHub，由 Vercel 自动部署。

当前进度：**阶段 1 至 3 已验收，阶段 4（AI 漫剧页与小游戏页）完成，待验收**。详见 `docs/进度与待办.md`。

## 文件夹是干什么的

```
index.html            主界面（入口），内容来自 data/，互动脚本在 home/js/
feedback/             返图与反馈页
works/                作品与碎碎念页
drama/                AI 漫剧页
games/                小游戏页（games/play/ 下每个游戏一个独立文件夹）
core/                 全站共用：外壳（导航、下单栏）、数据读取、基础样式
themes/               主题。每个主题一个文件夹（theme.css 是全站变量与皮肤，home.css 是主界面皮肤）
data/                 全部内容数据（价目、排单状态、联系方式等），详见 data/README.md
assets/               图片素材（作品图、封面等）
tools/                检查脚本
docs/                 进度与待办
```

每个页面是独立的小沙盒：自己的 HTML、自己的 `page.js`、自己的 `page.css`。某个页面或某个数据文件出错，不会拖垮其他页面。

## 部署：GitHub 网页上传 + Vercel

1. 解压压缩包。
2. 在 GitHub 新建一个仓库，进入“上传已有文件”，把解压后文件夹**里面的全部内容**拖进去（不要多套一层外层文件夹）。文件多时可以分几次上传。提交。
3. 在 Vercel 里导入这个仓库。框架选 `Other`，构建命令和输出目录都留空。点部署。
4. 之后每次在 GitHub 网页上传新文件或修改文件并提交，Vercel 会自动重新部署，几十秒后生效。
5. 绑定自己的域名：Vercel 项目的 Domains 设置里添加。

关于托管方案（Vercel 免费版是否适用于带价目的站点）和国内访问，见 `docs/进度与待办.md` 的“待站主确认”。

## 阶段 4（AI 漫剧页与小游戏页）验收清单

这一阶段没有真实的漫剧和游戏，所以验收的是占位、结构和间距。请手机和电脑各看一遍：

1. **间距。** 主界面五章之间的空白明显变小，章与章之间有一条细线加菱形的分隔装饰；作品页、漫剧页、小游戏页的板块之间同样更紧凑。觉得还是松或紧，告诉我，或者改 `core/base.css` 开头的 `--sl-gap-*` 四个值（子页面）、`themes/t1-starfield/home.css` 里的 `--chap-min`（主界面）。
2. **AI 漫剧页。** 顶部有“本页内容由 AI 生成”，下面是两个“占位 · 待上线”的虚线框。
3. **小游戏页。** 顶部有说明，下面一张“抓坏猫”卡片，标着“制作中”，点不动。
4. **试一试登记（可选）。** 在 `data/dramas.json` 里按 `data/README.md` 登记一部有真实 BV 号的漫剧，部署后点卡片应出现播放器，关掉窗口播放器消失。验完删掉即可。
5. **新增游戏的结构。** 打开 `games/play/README.txt`，确认新增游戏的步骤你能看懂；`抓坏猫` 的占位页在 `/games/play/catch-bad-cat/`。

## 阶段 3（作品与碎碎念页）验收清单

请你亲手加一张作品来验收（这是阶段 3 最重要的一步）：

1. 选一张图，压缩到宽度 1600 像素以内、500KB 以内。
2. 在 GitHub 里进入 `assets/works/divination/`，上传这张图。
3. 打开 `data/works.json`，在 `items` 里按 `data/README.md` 的写法加一项，提交。
4. 等 Vercel 部署完，打开 `/works/`：新作品出现在网格里，上方的分类按钮出现“占卜示例”并显示数量；点作品能看大图，左右可翻页；手机上标题在图片下方，电脑上鼠标移上去放大并显示标题。
5. 再在 `data/thoughts.json` 里加一条碎碎念，确认按日期从新到旧显示。
6. 验收完觉得是测试内容，把这两处改回去（删掉那一项，删图片）即可。

## 阶段 2（主界面）验收清单

打开部署好的首页，手机上看一遍：

1. **封面。** 深色夜空与月亮，月亮周围漂着四个小物件，点一下能跳到对应章节。定位语位置是占位。
2. **今日字卡。** 点“抽一张”，洗牌后选一张牌，翻出的是占位文案“字卡文案待站主提供”；点“夹进书里”后，当天不能再抽。
3. **四件星物。** 左右翻四页：占卜的纠缠水晶球、网站定制的代码演示、灵摆调频、AI 映画（进入前有“由 AI 生成”的提示）。业务介绍是占位。
4. **价目星牌。** 价格来自 `data/services.json`，改一个价格，这里和详情都会变。
5. **一封来信。** 点封蜡拆信，营业须知五章是占位；日程写着“日程待站主提供”，不再显示假的可约日期。
6. **悬浮球。** 点它展开章节菜单，“更多与设置”里能进入另外四个页面、开关简化动效。
7. **底部“下单与联系”。** 在主界面打开的是原型自带的联系弹层，里面有“复制预约消息”。

## 阶段 1 验收清单

打开部署好的网址，手机和电脑各看一遍：

1. **能上线。** 五个页面都能打开，地址是 `/`、`/feedback/`、`/works/`、`/drama/`、`/games/`。
2. **能切换。** 点右上角菜单，可以进入任意页面；主界面底部的“其他页面”列表也能进入。
3. **主题变量一处改，全站变。** 打开 `themes/t1-starfield/theme.css`，把 `--sl-bg` 那一行的颜色改掉，提交。部署后五个页面的背景色一起变。
4. **内容一处改，全站变。** 在 `data/services.json` 里改某个价格，主界面价目同步变；在 `data/status.json` 里把 `state` 改成 `open`，每个页面底部的排单状态一起变。
5. **动效可降级。** 菜单里的“简化动效”开关能关掉背景漂移；系统开启“减少动态效果”时默认就是简化。
6. **不会因为一个文件写错而整站崩掉。** 故意把某个 json 少写一个逗号，只有用到它的那一块显示错误提示，其余照常。改回去即可。
