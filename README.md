# Spark Light

Shadow 的个人服务站。多文件静态项目，不需要安装任何东西、不需要构建，直接放进 GitHub，由 Vercel 自动部署。

当前进度：**阶段 1 至 3 已验收，弹层美化与导航跳转已验收；返图与反馈页、作品页的新版界面（纯前端，未接后端）待验收；AI 漫剧页与小游戏页已按参考稿改版，待验收；加载页（引擎 + 一页“星盘与第十七张”）已完成并接到全部页面，待验收；《网站文字声明》全部文案、封面可展开介绍与 AI 内容点击解封马赛克已完成**。详见 `docs/进度与待办.md`。

## 文件夹是干什么的

```
index.html            主界面（入口），内容来自 data/，互动脚本在 home/js/
feedback/             返图与反馈页（page.js 入口；phone.js 电话与拨盘；memo.js 来电单；log.js 来电记录；api.js 后端接口，目前未接）
works/                作品与碎碎念页（page.js 入口；view-cf.js 展柜；view-grid.js 瀑布与按月份；lightbox.js 大图）
drama/                AI 漫剧页
games/                小游戏页（games/play/ 下每个游戏一个独立文件夹）
core/                 全站共用：外壳（导航、下单栏）、数据读取、基础样式、星光效果（spark.js）、动画循环（raf.js）、加载页引擎（loader.js + loader-boot.js + loader.css）
themes/               主题。每个主题一个文件夹（theme.css 是全站变量与皮肤，home.css 是主界面皮肤）
loaders/              进站时的加载页。registry.js 是注册表，每个加载页一个文件夹（arcanum 是“星盘与第十七张”，_template 是新加载页模板）
data/                 全部内容数据（价目、排单状态、联系方式等），详见 data/README.md
assets/               图片素材（作品图、封面等）
tools/                检查脚本
docs/                 进度与待办
```

每个页面是独立的小沙盒：自己的 HTML、自己的 `page.js`、自己的 `page.css`。某个页面或某个数据文件出错，不会拖垮其他页面。

## 部署：GitHub 网页上传 + Vercel

1. 解压压缩包。
2. 在 GitHub 新建一个仓库，进入“上传已有文件”，把解压后文件夹**里面的全部内容**拖进去（不要多套一层外层文件夹）。文件多时可以分几次上传。提交。
3. 在 Vercel 里导入这个仓库。框架选 `Other`，构建命令和输出目录都留空。点部署。
4. 之后每次在 GitHub 网页上传新文件或修改文件并提交，Vercel 会自动重新部署，几十秒后生效。
5. 绑定自己的域名：Vercel 项目的 Domains 设置里添加。

关于托管方案（Vercel 免费版是否适用于带价目的站点），见 `docs/进度与待办.md` 的“待站主确认”。

## 返图与反馈页、作品页（新版，纯前端）验收清单

这一轮只做界面，没有后端：返图页的口令暂时无法校验，也不会发出任何内容。请手机和电脑各看一遍：

1. **返图页封面。** 夜空里一部电话。点拨盘上的数字孔（或按住孔顺时针拖到挡片再松手）拨号，也可以点“改用键盘输入”。拨 4 位以上数字按“接通”，电话会响铃，随后读数屏提示“留言通道暂未开放”。这是正常的，后端接好之前不会开放。
2. **预览留言单。** 在网址后面加 `?preview=1`，例如 `你的网址/feedback/?preview=1`。预览模式下页面右下有“预览模式”提示，任意 4 位以上数字都能接通，接通后弹出来电单。选项目、写留言、传图（最多 4 张）、勾选同意、寄出：留言会以“待审核，仅你可见”出现在来电记录最前面，刷新就没了，什么都没有真的发出去。
3. **来电记录。** 站主还没登记留言时显示“还没有公开的来电”。登记后可以切换磁带和卡堆两种看法、按项目筛选、排序，点图片放大。登记方法见 `data/README.md` 的“登记返图与留言”。
4. **作品页。** 作品页上方是分类陈列架，每类一个会动的小图标，点一类只看那一类。可以在“展柜”（横向 3D 翻看，拖、甩、方向键都行）、“瀑布”、“按月份”三种陈列间切换，点作品看大图，大图里左右拖动换一件、往下拖关闭。作品要带 `date` 才会出现排序和“按月份”，写法见 `data/README.md`。
5. **碎碎念。** 还在作品页下半部分，是独立的一块，每条有大号日期，配图可以点开放大。
6. 简化动效（设置里的开关或系统“减少动态效果”）打开后，翻页和动画都应是瞬间切换。
7. 没有真机测过的部分：iOS 的触感震动、手机上拖拽拨盘和展柜的手感、低端手机上的流畅度。请重点在你自己的手机上拖一拖。

## 弹层美化与导航跳转验收清单

1. **弹层外观。** 手机和电脑上依次打开：主界面的悬浮球菜单、子页面顶部胶囊里的“更多与设置”、“下单与联系”、价目卡详情。面板边缘有淡淡的紫色微光，右上角有两颗错开节奏闪烁的小星，标题前有一颗小星；内容一行一行浮上来；按钮和列表行按下会回弹，关闭按钮会转一下。
2. **星光迸发。** 每次打开弹层，从你点的位置迸出一小撮星光，不到一秒消失。打开“简化动效”或系统开启“减少动态效果”后，不会迸星光，小星静止。
3. **悬浮球菜单。** 在原来的章节和“营业须知”之后，多了“其他页面”一组（返图与反馈、作品与碎碎念、AI 漫剧、小游戏），点一下直接跳过去。
4. **子页面的导航。** 顶部正中一颗胶囊（Spark Light + 会转的星）：鼠标移上去、或点一下，向下展开页面列表，当前页那一行带星并高亮；最下面是“更多与设置”，里面有“主界面各章”，点“价目星牌”会回到主界面并滑到那一章。主界面的悬浮球菜单没有改动。
5. **直接用地址。** 在浏览器地址栏输入 `你的网址/#letter`，打开后会滑到“一封来信”。
6. 觉得星光太多或太少、颜色不喜欢，把你的感受告诉我；颜色和节奏集中在 `themes/t1-starfield/theme.css` 末尾“弹层皮肤”一节，星光数量在 `core/spark.js`。

## AI 漫剧页与小游戏页（改版）验收清单

两页都按你给的参考稿重做：漫剧页是一座放映厅，小游戏页是一台方块游戏机。手机和电脑各看一遍：

1. **漫剧页现在的样子。** 打开 `/drama/`：标题下有英文小字“Spark Light 放映厅”，再下面是“本页内容由 AI 生成”的小徽标；中间是一块 16:9 银幕，还没有漫剧时，银幕里是片头倒数圈里的 0 和“待上线”；银幕下面是胶片条，只有一格“下一部作品”；再往下是灰色的“还没有上线”按钮。不再出现两张重复的虚线占位卡。
2. **登记一部试试（可选，建议做）。** 在 `data/dramas.json` 里按 `data/README.md` 加一项：长图用 `type: "images"` 加 `pages`（图片放 `assets/drama/<id>/`），视频用 `type: "bilibili"` 加 `bvid`。部署后刷新，银幕和胶片上就出现这一部；没有登记封面时，画面用参考稿里的四张线条插画（月亮、字卡、灯塔、纸鹤）轮流顶替，右上角标“封面待补”，登记了封面就用封面。胶片可以左右拖动（电脑上也能用鼠标拖，或用方向键），停在片门里的就是当前这一部。
3. **放映。** 点“开始放映”（视频）或“开始阅读”（长图）：页面关灯，一道光束从底部打到银幕，画面从银幕的位置放大飞过来；视频会先倒数 3-2-1 再加载播放器，长图是上下连续阅读，右上角显示读到第几页。
4. **退出与释放。** 点右上“退出放映”、按 Esc、或点画面外的黑边都能退出，退出后播放器和图片立刻释放；切到别的标签页再回来，放映会自动结束。
5. **小游戏页。** 打开 `/games/`：页头是“Spark Light 方块游戏机”，下面一台棋盘，每个游戏是一块墨色方块（现在是“抓坏猫”，方块里是那只白色线条猫，标着“制作中”），空位是纸面纹理的小方块。方块可以拖一拖（松手弹回），点黑色方块打开预览（沿用星盘面板，画面是夜景与走动的猫，标着“示意画面”），点“重新落下”重播下落动画。
6. **改成可以玩（可选）。** 把 `data/games.json` 里“抓坏猫”的 `status` 改成 `ready`，部署后点方块，预览里的按钮会变成“开始游戏”，点了进入 `/games/play/catch-bad-cat/`。新增游戏的步骤见 `games/play/README.txt`。
7. **简化动效。** 打开设置里的“简化动效”（或系统“减少动态效果”）：胶片切换、方块下落、关灯和画面飞行都变成瞬间完成，不倒数。
8. **间距（沿用阶段 4 的做法）。** 子页面板块间距仍是 `core/base.css` 开头的四个 `--sl-gap-*` 变量，觉得松紧不合适就改那里；主界面章节高度是 `themes/t1-starfield/home.css` 里的 `--chap-min`。
9. 没测的部分：真机（尤其 iOS 上关灯与光束的性能、触感震动）、真实的 B 站播放器（沙盒没有外网）、慢网络。请重点在你自己的手机上把两页都点一遍。

## 加载页（开屏）验收清单

只在**进入站点时**出现一次；站内点来点去不会重播。点一下（或按 Esc）立刻跳过。

1. 先在浏览器里清掉这个站点的数据，再用手机打开：
   - 黑底上出现一圈星盘与九张环游的塔罗牌，中间有乱码会一个个变成英文，下面配中文；
   - 大标题“火花照见微光，影中读取答案”逐字升起，英文副标题逐词浮现；
   - 底部是 `I / VI`、一条带菱形节点的细线、滚轮百分比，它们跟着真实加载走（不是假的）；
   - 大约 1 到 2 秒后，牌收回、中间的“星辰”牌翻转推出来、白光一闪，然后整层淡出。
2. 再打开一次（不要清数据）：不该再出现，直接进正文。这是“只出现一次”，不是坏了。
3. 页面一出来的瞬间点一下屏幕：应该立刻进入，不等动画走完。
4. 打开系统的“减少动态效果”再进站：不该有旋转与飞牌，应是一个静态画面 + 进度，很快结束。
5. 电脑上左右移动鼠标：星盘会轻微跟着倾斜（手机上没这个效果，正常）。
6. 觉得太快或太慢、字太小、星盘太大，直接说。节奏在 `core/loader.js` 开头的 `MIN_MS` / `MAX_MS`，尺寸在 `loaders/arcanum/loader.css` 的 `--ar-s`。

## 阶段 1 验收清单

打开部署好的网址，手机和电脑各看一遍：

1. **能上线。** 五个页面都能打开，地址是 `/`、`/feedback/`、`/works/`、`/drama/`、`/games/`。
2. **能切换。** 子页面点顶部胶囊、主界面点悬浮球，都可以进入任意页面；主界面底部的“其他页面”列表也能进入。
3. **主题变量一处改，全站变。** 打开 `themes/t1-starfield/theme.css`，把 `--sl-bg` 那一行的颜色改掉，提交。部署后五个页面的背景色一起变。

6. **不会因为一个文件写错而整站崩掉。** 故意把某个 json 少写一个逗号，只有用到它的那一块显示错误提示，其余照常。改回去即可。
