## 二、本轮已完成并已验证的修改

本轮目标是恢复主题 3「像素街机」的页面层次、字体与主要舞台结构。

1. **街机字体接入**
   - `index.html` 新增 `Press Start 2P` 与 `DotGothic16` 的非阻塞字体加载。
   - `themes/t3-arcade/home.css` 使用 `DotGothic16` 作为正文，使用 `Press Start 2P` 作为像素标题和按钮字体。
   - 浏览器实测字体计算值为：正文 `DotGothic16`，显示字体 `Press Start 2P`。

2. **街机主界面结构修复**
   - `themes/t3-arcade/home.js` 挂载主题时继续先清空 `#main`，只保留一个 `#t3-stage`，避免旧主题节点影响页面高度、焦点和按钮布局。
   - 保留原有四台服务街机、价目货架、通关须知、每日字卡和底部信息。

3. **根据像素街机原型补齐舞台**
   - 新增「火花街」场景：像素天空、月亮、云层、星点、四间店铺、道路和时间控制条。
   - 新增「道具商店」场景：RUI 店员、货架道具、从 `data` 服务数据读取的名称和价格。
   - 新增「今日一张」像素小游戏：Canvas 画面、按钮和今日字卡反馈。
   - 店铺、货架、小游戏均有点击反馈；时间控制可切换清晨、白天、黄昏和夜晚视觉。

4. **安全与验证**
   - 动态文本均通过 `textContent` 写入。
   - 没有新增 Emoji。
   - 已通过 `node --check themes/t3-arcade/home.js`。
   - 已通过 `git diff --check`。
   - 已在本地浏览器验证插入硬币、街道、商店、时间切换和字体渲染；浏览器无新增 error/warn 日志。
