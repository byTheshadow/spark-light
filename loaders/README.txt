加载页（进站时的开屏）
==================================================

这个文件夹放“进站时出现一次”的加载页。引擎在 core/loader.js，规则来自
docs/启动包-v5.md：

  - 只在进入站点时出现一次，站内跳转不再出现（存在 sessionStorage 的 sl.loader.seen）
  - 点一下（或 Esc / 回车 / 空格）立刻跳过
  - 最短约 0.62 秒，进度最多 1.5 秒推满，之后还有约 1 秒收尾
  - 出错或超时就整层消失，绝不把站卡住

现有的
  arcanum/   星盘与第十七张：黑底星云、五层自转星盘、环游塔罗牌，进度满时揭牌“星辰”

新增一个
  1. 新建文件夹 loaders/<id>/（先放一个 README.txt，GitHub 网页端不能传空文件夹）
  2. 照 _template/ 里的 loader.js 与 loader.css 写
  3. 在 loaders/registry.js 里加一行，status 改成 'ready'
  4. 多个加载页会随机切换，并且尽量不和上一次重复；weight 调出现概率

注意
  - 新增文件夹要放 README.txt，否则 GitHub 网页端上传时文件夹会是空的
  - 加载页的文案写在自己文件夹里；站名之类不从这里读
